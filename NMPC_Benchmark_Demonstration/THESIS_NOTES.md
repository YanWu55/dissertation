# Mapping the generated outputs to Chapter 5

## 5.3 Cart-Pole

Use:

- `CP1_state_response.png` for the state-response figure.
- `CP1_input_phase.png` for the control-input / phase-plane figure.
- `CP1_cartpole_metrics.csv` for Section 5.3.6.
- `CP1_solver_diagnostics.png` only if computational performance is discussed.

Recommended wording must be based on the actual numbers generated by MATLAB.

## 5.5 Cross-System Comparison

Use:

- `cross_system_comparison.csv`

Do not interpret raw physical quantities across systems as directly comparable.
The cross-system comparison should focus on:

1. whether the objective is achieved;
2. constraint satisfaction;
3. dimensionless/normalised regulation error;
4. computational demand;
5. how the different nonlinear structures influence the same NMPC framework.

## Verification wording

These scripts perform numerical closed-loop simulations only.

Allowed wording:
- "No constraint violation was observed for the benchmark trajectory."
- "The simulated trajectory remained within the prescribed bounds."

Avoid:
- "The closed-loop system is formally verified safe."
- "Safety is guaranteed for the initial set."

unless an independent formal verification method is applied.
